# f10w-0x00.github.io

Personal Dashboard, Technical Notes, and Digital Garden.

- **URL**: [https://f10w-0x00.github.io](https://f10w-0x00.github.io)
- **Engine**: Jekyll (GitHub Pages Native)
- **Categories**: `Note` | `Week` | `CheatSheet`

### ✨ Key Features

1. **Dashboard (`/`)**:
   - Live GitHub Contributions Heatmap in `#2563EB` theme
   - Direct category access to `Note`, `Week`, and `CheatSheet`
2. **Blog Stream (`/blog/`)**:
   - Zero pagination, infinite smooth reading
   - Real-time tag pills for instant filtering (`All`, `Note`, `Week`, `CheatSheet`)
3. **Accompany Files & 6:4 Split Pane**:
   - Files in `accompany/` are invisible in the public blog stream
   - Clicking any accompany link (e.g. `[视频笔记.md](/accompany/linear-algebra-video-notes/)`) opens a 6:4 Golden Ratio split panel on the right side with zero page reloads
   - Split panel features the Antigravity-style split-view icon and independent scrolling
4. **Developer Experience**:
   - Native MathJax 3 LaTeX equation rendering
   - One-click Code Block copy button
   - Ultra-lightweight reading progress bar pinned to the top of the viewport
